Quem sou eu?

Sou Tawane Grigorio, tenho 23 anos e estou construindo minha trajetória na área de tecnologia. Minha história com a programação começou a partir de uma mudança de carreira, encontrei na programação um tipo de desafio que me interessa: existe sempre alguma coisa para entender melhor, testar ou fazer de uma maneira diferente. Tenho construído projetos para compreender, na prática, como uma aplicação é estruturada e como código, interface e interação se relacionam. Minha base está em HTML, CSS e JavaScript, enquanto avanço nos estudos de Git, APIs e React. Busco minha primeira oportunidade em desenvolvimento para continuar esse processo em um ambiente real, contribuindo com o que já sei e evoluindo a partir dos problemas que ainda não sei resolver.

Meus projetos:

Site fotografia

Desenvolvimento de um site para uma fotógrafa, criado com o objetivo de apresentar seu trabalho. O projeto possui uma identidade visual elegante e moderna, com seções para apresentação profissional, portfólio, depoimentos, pacotes de ensaio e formulário de contato integrado ao WhatsApp.

Tela login

Criação de uma tela de login com uma proposta visual simples e organizada, desenvolvida para praticar a construção de interfaces utilizando HTML e CSS.

Portfólio Pessoal

Projeto desenvolvido para apresentar minha trajetória em tecnologia, conhecimentos e projetos em Front-End. A interface foi criada do zero, utilizando HTML, CSS e JavaScript, com foco em identidade visual, organização e navegação.
